# Picture credits

Every product picture in `public/products` is an original illustration drawn for Tenga.

They are not photographs. They are not copied from ShopRite, Pick n Pay, Choppies, Spar, Food Lover's Market, Game, Melissa, Cheers, Toppy's, Young Heroes, or from any brand site. Labels on the drawings say what the thing is (meal, mayo, water, salt) rather than reproducing a trademark.

No Unsplash, Pexels, or other stock library was used, so there is no third-party licence to attribute. The illustrations are part of this project. Regenerate them, after a catalogue edit, with:

```bash
npm run images
```

That command runs `scripts/render-products.ts` and writes one optimised WebP per size and scent.
